About

TaskManager is a user-friendly web application designed to simplify task management. Users can create, edit, organize, and track tasks with support for parent and sub-task relationships. Built using Java Spring Boot, Thymeleaf, and MySQL, it ensures smooth performance and scalability.

Description

TaskManager helps individuals and teams manage their workflows efficiently. Users can assign task statuses (Pending, In Progress, Completed), organize tasks hierarchically, and easily track progress. It is suitable for personal productivity as well as collaborative project management.

Features
Add, edit, and delete tasks
Parent and sub-task management
Track task status (Pending, In Progress, Completed)
User-friendly interface with validation
Task filtering and search
